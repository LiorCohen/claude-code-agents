## Systemic Violations

### 1. Missing output schemas for scaffolding skills (6 skills)

All six component scaffolding skills have `input.schema.json` but no `output.schema.json`. Each skill's SKILL.md references an Input schema but does not mention an Output section or schema. Per the skills-standards, skills that produce structured output must define an output schema.

**Affected skills:**
- `backend-scaffolding`
- `config-scaffolding`
- `contract-scaffolding`
- `database-scaffolding`
- `frontend-scaffolding`
- `helm-scaffolding`

**Evidence:** Each skill has `## Input` with a schema reference, but no `## Output` section. The scaffolding engine produces results (files created, errors) that should be documented.

**Recommendation:** Either add `output.schema.json` to each skill, or add a note: "Output is handled by the scaffolding engine and follows the engine's output format." A shared schema reference would suffice.
