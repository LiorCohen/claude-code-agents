# Task 143: Add sdd-architect skill for architectural Q&A and gap analysis

Add an `sdd-architect` skill to the plugin that serves as an interactive architectural guide for SDD users. The skill should help users:

- **Ask questions** about SDD's architectural choices (CMDO, MVVM, component separation, etc.)
- **Learn** about the system's design decisions and the reasoning behind them
- **Understand** how components interact, what patterns are enforced, and why
- **Identify gaps** — point out areas where the architecture may be incomplete, inconsistent, or could be improved

This is a user-facing skill meant for exploration and education, not for generating code or scaffolding.
