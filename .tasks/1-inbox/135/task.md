# Add installation instructions defaulting to user scope

Add installation instructions that make the plugin installation scope default to user (`--scope user`), so the plugin is available across all projects. If installed to local/project scope, the plugin may not show up in new projects.

Installation docs should explicitly instruct users to never install to local or project scope.
